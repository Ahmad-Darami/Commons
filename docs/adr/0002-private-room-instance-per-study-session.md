# Each Study Session gets its own private Room Instance

When two Study Groups open the same Room at the same time, each gets its own private copy, a Room Instance. Neither group sees nor hears the other. The alternatives were:
- blocking the second group, as a real library would, which needs a reservation system to be fair
- putting both groups in one shared copy at different Tables, which small study rooms (often a single Table) can't support

Private copies mean no waiting and no conflicts. Each Study Session's voice and sync channel is keyed to its Study Group, not to the Room.

## Consequences

- A Room can never be "full" in the MVP, so popular Rooms don't need reservations.
- Students never bump into other groups. That serendipity comes back later, with shared Room Instances in big Rooms (several Study Sessions at different Tables), which would need its own decision.
